# API для Yatube

## Описание
Проект представляет собой REST API для социальной сети Yatube. 
Он позволяет пользователям публиковать посты, оставлять комментарии, 
объединяться в группы и подписываться на других авторов.

### Основные возможности:
- Аутентификация по JWT-токенам.
- Создание, редактирование и удаление постов и комментариев (только для авторизованных авторов).
- Просмотр групп и постов (доступно всем).
- Подписка на пользователей и просмотр своих подписок (с поиском).
